# Google Ads API — Asset Manager (Python)

A beginner-friendly starter project to **store**, **fetch**, and **use** Google Ads
assets (text, image, video, sitelinks) via the official Google Ads API.

---

## 0. The big picture

An **Asset** is a reusable creative block (a headline, an image, a YouTube video,
a sitelink). You create it once → it's stored in your account with an ID →
you link it to campaigns/ads to make it show up.

This project gives you three building blocks:

| Script                      | What it does                                  |
|-----------------------------|-----------------------------------------------|
| `store_assets.py`           | Create/upload assets (text, image, video, sitelink) |
| `fetch_assets.py`           | List assets already in your account (GAQL)    |
| `use_assets.py`             | Link a stored asset to a campaign             |
| `create_campaign.py`        | Create a paused Search campaign               |
| `create_demandgen_campaign.py` | One-off Demand Gen campaign with a video ad |
| `ads_toolkit.py`            | Reusable library (store/fetch/download/use)   |
| `make_video_campaigns.py`   | Build many Demand Gen video campaigns via the toolkit |
| `download_assets.py`        | Save image files to ./downloads; export video YouTube links |
| `download_youtube_videos.py` | Optional: download YouTube **video files** with yt-dlp (your own videos only) |

### Notes on video

* Video assets are **YouTube references** (a video id) — you cannot upload a
  local `.mp4`; put it on YouTube first, then use its id.
* Classic **Video campaigns are read-only** in the API. Use **Demand Gen**
  (what `ads_toolkit` builds) to serve video programmatically.
* Download saves **image files**; for video the API exposes only the
  **YouTube link**, not the raw file.
* To get a video **file** locally, use `download_youtube_videos.py` (needs the
  optional `yt-dlp` dependency: `pip install -r requirements-optional.txt`).
  **Only download videos you own or have rights to** — downloading other
  people's videos violates YouTube's Terms of Service.

## 1. Credentials you need (do these in the browser first)

You need **5 things**. See the chat walkthrough for full detail. Short version:

1. **Google Ads account** → gives a 10-digit **Customer ID**.
2. **Manager (MCC) account** → needed to access the API Center.
3. **Developer Token** → Manager account → Tools & Settings → API Center.
4. **Google Cloud project** → enable "Google Ads API" + create an
   **OAuth Client ID (Desktop app)** → gives **Client ID** + **Client Secret**.
5. **Refresh Token** → generated by running `generate_refresh_token.py` (step 4 below).

> 💡 Start with a **Test Account** (created inside your Manager account). Your
> developer token has "Test Account" access by default — perfect for learning,
> no money spent.

## 3. Configure

Copy the template and fill in your values:

```powershell
copy google-ads.example.yaml google-ads.yaml
```

Open `google-ads.yaml` and paste in your developer token, client id, and
client secret. (Refresh token comes in the next step.)

---

## 4. Generate your refresh token

```powershell
python generate_refresh_token.py
```

It opens a browser → approve access → prints a **refresh token**.
Paste it into `google-ads.yaml`.

## 6. Create video ads (Demand Gen) — step by step

Classic YouTube/Video campaigns **cannot** be created through the API (they are
read-only). The supported way to serve video programmatically is a **Demand Gen**
campaign, which this project builds for you.

### Step 1 — Get your YouTube video ID

A video asset in Google Ads is just a **reference to a YouTube video**, so your
video must already be uploaded to YouTube. The "video ID" is the part after
`v=` in the URL:

```
https://www.youtube.com/watch?v=dQw4w9WgXcQ
                                 └────┬────┘
                              this is the video ID
```

Short links work the same way: `https://youtu.be/dQw4w9WgXcQ` → ID is `dQw4w9WgXcQ`.

> On a **real** account the video must be on **your own YouTube channel**, or the
> ad will be disapproved. On a **test** account any public video ID works.

### Step 2 — Put the video ID into the campaign definition

Open `make_video_campaigns.py` and edit the `CAMPAIGNS` list. Each entry is one
campaign; set `youtube_video_id` to your ID:

```python
CAMPAIGNS = [
    {
        "campaign_name": "My Video Campaign",
        "youtube_video_id": "dQw4w9WgXcQ",   # <-- PUT YOUR VIDEO ID HERE
        "business_name": "Your Brand",
        "headlines": ["Headline 1", "Headline 2"],
        "descriptions": ["Description 1.", "Description 2."],
        "final_url": "https://yoursite.com",
    },
    # add more dicts here to create more campaigns in one run
]
```

Add as many entries as you want — each becomes a separate campaign.

### Step 3 — Run it

```powershell
python make_video_campaigns.py
```

It prints the created campaign / ad / video resource names. Each campaign is
created **paused** (it won't serve or spend).

### Step 4 — Verify

```powershell
python fetch_assets.py        # see your video asset is stored
```

Or query Demand Gen ads directly with the API (see the chat for an example).

### Step 5 — Download assets locally (optional)

```powershell
python download_assets.py
```

* Image assets are saved to `./downloads/`.
* Video assets can't be downloaded via the API, so their **YouTube links** are
  written to `./downloads/video_links.txt`.

### How the video ID flows through the code

```
make_video_campaigns.py   "youtube_video_id": "..."
        v
ads_toolkit.create_demandgen_video_campaign(youtube_video_id=...)
        v
ads_toolkit.add_youtube_video_asset(...)
        asset.youtube_video_asset.youtube_video_id = youtube_video_id   <-- stored here
        v
attached to the Demand Gen video ad
```

### Use an existing video asset instead of an ID

If you already stored a video, pass its resource name instead of an ID:

```python
{
    "campaign_name": "Reuse Video",
    "video_asset": "customers/8076057701/assets/375600965428",  # instead of youtube_video_id
    ...
}
```

### Things that can go wrong (and the fix)

| Error | Meaning | Fix |
|-------|---------|-----|
| `MUTATE_NOT_ALLOWED` | Tried to create a classic Video campaign | Use Demand Gen (this project) |
| `DESTINATION_NOT_WORKING` | The `final_url` returns an error / 404 | Use a working URL (the builder also ignores this topic for test URLs) |
| `DUPLICATE_CAMPAIGN_NAME` | Campaign name already used | Use a unique name (the example adds a random suffix) |
| Ad disapproved (PROHIBITED) | Video not on your channel / bad URL | Use your own YouTube video and a live URL |
